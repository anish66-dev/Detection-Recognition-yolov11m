# Archietecture

### CV & ML

- **YOLO11m** — person + pedestrian detection
- **InsightFace** — face detection + embedding extraction
- **ByteTrack / BoT-SORT** — multi-object tracking, persistent IDs across frames
- **CSRNet / DM-Count / CrowdFormer**— crowd density estimation
- **OpenCV** — frame decoding, preprocessing, polygon rendering
- **FFmpeg** — RTSP stream ingestion
- **OSNet** — body ReID

### Backend

- **FastAPI** — API server + WebSocket server
- **SQLAlchemy** — ORM
- **PostgreSQL + pgvector** — primary database + vector similarity search
- **Alembic** — schema migrations
- **Celery** — async task workers within event processing service
- **Redis** — inter-service message bus + Celery broker + cache + rate limiting
- **MinIO** — object storage (event snapshots, video clips, reports)
- **Pydantic** — shared event schema contracts across all services

### Infrastructure

- **Docker + Docker Compose** — containerization + orchestration
- **Nginx** — reverse proxy, TLS termination
- **Prometheus + Grafana** — metrics + dashboards
- **Loki** — log aggregation
- **OpenTelemetry** — distributed tracing across service boundaries

### Frontend

- **React + TypeScript** — dashboard
- **Tailwind CSS** — styling
- **TanStack Query** — data fetching + client cache
- **Socket.IO** — real-time alert delivery
- **Konva.js** — zone polygon drawing on camera canvas
