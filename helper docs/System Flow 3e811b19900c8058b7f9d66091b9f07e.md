### Event Contract

Every message on a Redis stream is a Pydantic model defined in `shared/schemas`. Nothing gets published without a validated schema. Nothing gets consumed without parsing against a schema.

| Stream | Schema | Producer | Consumers |
| --- | --- | --- | --- |
| `frames:{camera_id}` | `FrameEvent` | Ingestion | Detection |
| `events:detections` | `DetectionEvent` | Detection | Recognition, Event Workers |
| `events:recognitions` | `RecognitionEvent` | Recognition | Event Workers |
| `alerts:live` | `AlertEvent` | Event Workers | API Server → Dashboard |

### Inter-Service Communication Rules

- **No service calls another service's HTTP API** — all async communication through Redis streams
- **No service reads another service's DB tables directly** — cross-domain reads go through the API server
- **Audit writes are synchronous** — written in the same DB transaction as the triggering action, never async
- **Shared packages are libraries, not services** — mounted as local packages, not deployed separately
- **All events are immutable** — once written to PostgreSQL, events are never updated, only superseded by new events
